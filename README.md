# Amadora Boutique

Image-free bilingual ecommerce demo for Amadora Boutique, an Abu Dhabi-based fashion business.

- Instagram: https://www.instagram.com/amadora.boutique19/
- Product imagery intentionally omitted until supplied by the business.
- No WhatsApp number was publicly available at build time.

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run lint
npm run build
```
